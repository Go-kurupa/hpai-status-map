# 鳥インフル発生状況マップ

全国の養鶏家が、冬のあいだ毎朝開けるようにする「発生の地図と記録の道具」です。Built with Claude: Japan 2026 のテーマ 1（あなたにしかない深さを。）で応募します。

- **誰の**: 冬のあいだ、鳥インフルエンザの発生を気にしている養鶏家。作者は小規模な養鶏場の当事者で、この冬、自分の農場で使う予定です。
- **どんな課題を**: 作者のところには、家畜保健衛生所（家保）の連絡が、県外や海外の発生まで逐一届きます。足りないのは全国の俯瞰と過去です。1 通ずつでは他人事になり、実際に近くで発生したとき、作者は怖い思いをしました。平時の記録と報告、近隣への説明にも手がかかります。
- **どう解決するか**: 家保の速報を、全国の俯瞰と過去で補います。日本地図で全国の件数と自分の町の周辺の過去を事実として見て、去年の波が近づく様子を再現で確かめ、備えを切り替えるときの確認事項と声かけ文の下書きを手に入れます。平時は点検と死亡数を記録して報告文を作れます。AI は読み取りと下書き、決まりはコード、確定は人です。

## 何のための道具か

養鶏家は、鳥インフルエンザの発生を、家畜保健衛生所（家保）の連絡で知ります。作者のところには、県外や海外の発生まで逐一届きます。作品の価値は「家保より早い」ことではありません。届くのは 1 件ずつの速報で、全国でどこに集中しているか、過去にどこで出たかは見えません。1 通ずつでは他人事になり、実際に近くで発生したとき、作者は怖い思いをしました。この道具は、家保の速報を全国の俯瞰と過去で補い、他人事でなくします。足りないのは次の 5 つです。

1. **全国の俯瞰。** 国と 47 都道府県と環境省の発表は、別々の場所にあります。全国の今季と直近 14 日の件数、過去のシーズンの同じ日までの件数、野鳥の陽性を、画面の札と、変化があった朝のメールの 1 通にまとめます。
2. **過去も見て、他人事にしないこと。** 今季の発生が 0 件でも、周辺の町で出ていたと分かれば備えられます。国の資料にある過去 6 シーズンの事例は 247 件（52、25、84、11、51、24）ですが、公的な資料は PDF の一覧で、町ごとには見られません。町ごとの表と、約 60 km 以内の町の過去の表にしました。
3. **備えの切り替え。** 作者は、全国で増えれば消毒を徹底し、地域に寄れば働く人への注意喚起と車両の消毒を徹底します。コロナの流行時に各自が対策を強めたのと同じ動きです。切り替えの基準は作品が決めず、農場が決めます。作品は、発生が距離の輪に入る様子と、確認事項と声かけ文の下書きを出します。
4. **平時の記録と報告。** シーズン中は、毎月の自己点検と死亡羽数の報告を家保に出します。記録と提出を、人がつないでいます。
5. **近隣への説明。** 問い合わせや、鶏舎への無断の立ち入りがあります。説明の資料を農家が自分で作っています。

**やらないこと。** 近くに何もないことを理由に、問題がないと読める表示はしません。区域に入った、入っていないの断定はしません（判定は「可能性」にとどめ、県の連絡を正とします）。距離の輪と約 60 km の帯は距離の目安で、発表の区域ではありません。農場を点で示さず、農場の位置を推定しません。サーバーに保存する位置は約 1km のマス目までで、正確な地点は端末からも送りません。人の健康の質問や防疫の判断に、AI は答えません。家保への報告は自動で送らず、人が確かめて自分で出します。

## Claude の使い方

### 作品の中

| 役割 | 内容 | Claude を使わない部分 |
|---|---|---|
| 読み取り（`claude-opus-5-5`） | 形式の揃わない 47 都道府県の発表を、構造にする | 引用の検査、国との突き合わせ |
| 二重読み（`claude-haiku-5-5`） | 別のモデルが独立に読み、一致を確かめる | 一致の判定（プログラム） |
| 入口を直すエージェント（`claude-sonnet-5-5`） | 県のページが消えたり年度で変わったりしたとき、その県のサイトの中だけを探し、新しい入口を提案する | 取得の作法、承認（人） |
| 舞台裏 | 読み取りと検査の過程を、再現モードで見せる | 検査（プログラム） |
| 声かけ文、説明文 | 事実から、伝わる文を下書きする | 事実の検査、確定（人） |
| 毎朝の全国まとめの総括（`claude-sonnet-5-5`） | 全国の公開の事実を、1 文にまとめる | 件数、町、距離、野鳥、シーズン比の定型。文が許した語だけでできているかと、件数と項目、町と段階の組の検査。何か残れば総括を外して定型だけを送る |

- **読み取りと二重読み。** 読み取りの試験に通るまでは、すべての発表を「確認中」として出します（自動で載せません）。照合に不合格なら、県名と原文へのリンクだけを出します。
- **入口を直すエージェント。** Claude Managed Agents の定期実行（週に 1 回）で動かします。自由な Web 検索と Web fetch は使いません。取得は作品側の内部用 MCP の道具だけを通し、同じ県のドメインに限ります。出力は提案だけで、見回り先は自動では変わりません。運営者が承認します。
- **MCP。** 公開の MCP（読み取り専用の 4 道具）と、エージェントだけが使う内部用の MCP（認証つき）を分けています。

### 開発（Claude Code）

開発は Claude Code だけで行いました。**Codex は使っていません。ローカル LLM は使っていません。** 設計、実装、修正、試験、調査、レビューをすべて Claude Code の中で行いました。

- **スキル**: 読み取りの試験を走らせるスキル（`read-eval`）、47 都道府県の入口を決まった作法で確かめて表にするスキル（`entrance-check`）。
- **hook**: commit の前に、公開してはいけない内容（非公開の資料、鍵、個人のメールや電話番号の形）が混ざらないかを調べる hook（`.claude/hooks/public-precommit.sh`）。
- **サブエージェント**: 調査役（`researcher`、Sonnet）、レビュー役（`code-reviewer`、Opus）、セキュリティの点検役（`security-reviewer`、Opus）。実装とレビューを分けました。調査は分けて任せ、メインのセッションが原本で確かめました。
- **MCP**: 作品の公開の MCP と内部用の MCP を、この開発の中で作りました。

どの作業にどのモデルを使ったかは [docs/claude-code-usage.md](docs/claude-code-usage.md)、思っていたことが実測で違った場面は [docs/trial-and-error.md](docs/trial-and-error.md) に残しています。

## 判定と AI の分担

**AI は読み取りと下書き、決まりはコード、確定は人。** 区域、段階、解除の見込み、死亡率の計算、誰に送るか、確認リストは、決まりとしてコードで作ります。Claude に判断させません。Claude の出力は、検査を通ったものだけを画面に出し、迷うときは何もせず、人が確かめて確定します。

| 誰が | すること |
|---|---|
| Claude | 発表の読み取り、二重読み、声かけ文や説明文の下書き、毎朝の全国まとめの総括 1 文、入口の提案 |
| コード | 引用の検査、国との突き合わせ、一致の判定、段階、解除の見込み、死亡率、確認リスト、メールの宛先、毎朝の全国まとめの定型と総括の検査 |
| 人 | 否定の確定、入口の提案の承認、声かけ文の確定、家保への報告 |

段階は ① 区域に入っている可能性、② 隣町で発生、③ 約 60 km 以内か、よく行き来する町で発生、④ 全国の動き。地点の 3 次メッシュ（約 1km のマス目）の中心から発生市町村の面までの最短距離に、誤差 0.85km を足し、基準の 10km と比べます。① は移動制限区域の解除まで続けます。③ の距離の帯は、同じマス目から発生市町村の面までの最短距離が約 60 km 以内かを見て、画面に「約 N km 先で発生しました」と出します。① ② に当たらない発生に使い、移動制限の解除の後も帯に数えます。距離の目安で、区域の判定には使いません。事例ごとのメールには入れず、画面と毎朝の全国まとめに任せます。測り方と限界は [docs/data-sources.md](docs/data-sources.md)、段階が何回当たるかの数え方は校正の記録 [docs/level-calibration.md](docs/level-calibration.md) にあります。

## 公開 API と MCP

読み取り専用で、認証はありません。返すのは公開された事実だけで、会員の農場、地点、記録は含みません。使い方の全文は [docs/mcp-usage.md](docs/mcp-usage.md)。

| API | 内容 |
|---|---|
| `/api/v1/cases` | 事例の一覧（`season`、`pref`） |
| `/api/v1/areas/{市町村コード}` | その市町村の状態と、隣の市町村の発生 |
| `/api/v1/watch-status` | 47 都道府県の見回りの確認状況 |
| `/api/v1/wild-birds` | 野鳥の検査 |

| MCP の道具（`/mcp`、Streamable HTTP） | 内容 |
|---|---|
| `list_cases` | 事例の一覧 |
| `get_area_status` | 市町村の状態 |
| `get_watch_status` | 見回りの確認状況 |
| `get_official_guidance` | 国の機関の公式の文（出典と確認日つき） |

```
claude mcp add --transport http hpai https://hpai-status-map.web.app/mcp
```

**利用条件。** 読み取り専用です。認証はありません。1 つの IP につき毎分 60 回までで、超えると 429 を返します。すべての答えに「いつ時点か」と出典の URL が付きます。答えの `notices` は、利用者に必ず伝えてください。**県の連絡が正です。** 件数が少なくても、シーズン中はどこでも感染のリスクがあります。件数が 0 でも、確認できていない県の「載っていない」は未確認です。データそのものの出典と条件は、下の「外部のデータと素材」にあります。

## 限界

- **県の連絡が正です。** 公開情報だけでは、区域に入ったかを機械的に判定できません。判定は「可能性」で、家保の連絡は公開の発表より早いことがあります。
- **確認できません。** 古い TLS などで届かない入口は、TLS の検証を緩めず、「確認できません」と画面に出し、国の発表で補います。全県を確認できたときは「47 都道府県すべてを確認しました。」、確認できない県があるときは「47 都道府県のうち N 件を確認、M 件は確認できていません（県名）」と、時刻つきで常に出します。県の発生を検知できる根拠がない県もあります（[docs/data-sources.md](docs/data-sources.md)）。
- **見回りが県の発表をすべて拾える保証はありません。** 発生時に、県の常設ページや RSS が実際に動くかは、今季の最初の発生まで確かめられません（手順は [docs/first-outbreak-log.md](docs/first-outbreak-log.md)）。
- **入口を直すエージェントの失敗の検知。** 実行が途中で止まった場合（予算の上限、承認待ち、拒否、再試行の使い切り）は失敗として運営者に知らせます。`end_turn` で終わった実行は、入口を見つけられずに終わった場合も、失敗に数えません。
- 自己点検や死亡数の様式、期限、報告の方法は県や家保で違います。全国の様式には対応しません。
- 国の報告書は「基準を守っていても発生した」と書いています。確認リストは、発生を防ぐ保証をしません。
- 形の簡略化で、幅がおよそ 60m 未満の小さな島や岩は消えます。その分は誤差の 0.85km で覆えません（測った値は [docs/data-sources.md](docs/data-sources.md)）。
- **未実測のもの。** 記録に測った値が書かれていないものは、未実測です。たとえば、再現 1 回分のトークン数、読み取りの試験の正解率、スマホでの地図の動き、入口を直すエージェントの実物での動き、毎朝の全国まとめの本番での動き（模擬環境の試験だけで確かめています）は、実行の記録（[docs/cost.md](docs/cost.md)、[docs/read-eval-log.md](docs/read-eval-log.md)、[docs/map-acceptance.md](docs/map-acceptance.md)、[docs/agent-eval.md](docs/agent-eval.md)）に結果が書かれるまでは未実測です。効果を数字で言うときは、実測した値だけを使います。

## 費用

Claude の費用は、提供された API の枠があるうちは枠から出ます。枠の期限は未確認です。枠の後は、読み取りの費用に加えて、入口を直すエージェントの費用も `usage` で数え、月 10,000 円で読み取りを止める（8,000 円で進捗の読み取りと下書きを止める。予算の通知は 3,000 円）。見積もり（推定）と、実測の手順は [docs/cost.md](docs/cost.md)、呼び出しごとの記録は [docs/api-credit-usage.md](docs/api-credit-usage.md)、Batch の使い方は [docs/batch-usage.md](docs/batch-usage.md) にあります。測るまでは、円とドルの数字は見積もり（推定）です。

## 動かし方（開発者向け）

Node 24 が要ります。

```
npm install
npm test            # 共通、サーバー、画面、スクリプトの試験
npm run typecheck
npm run build       # 地図のデータを写し、画面とサーバーを束ねる
npm run dev -w web  # 画面を開発用に起動する（同じ LAN の別の端末から開ける）
```

模擬環境での公開 MCP の試し方は [docs/mcp-usage.md](docs/mcp-usage.md) にあります。本番に出したあとの動作確認は `npx tsx scripts/smoke-prod.ts`、公開の前の確認は `npx tsx scripts/smoke-prod.ts --pre-publish` です（手順は [docs/submission-checklist.md](docs/submission-checklist.md)）。
