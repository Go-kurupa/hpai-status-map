# 地図の受け入れ確認

設計書 §16「地図」の条件を、普及価格帯のスマホで人が確かめる手順と記録。**まだ誰も確かめていない。** 下の結果の欄は空のままにしてあり、確かめた人が書く。数字を推測で埋めない。

- 合格の条件（設計書 §16）: 日本全体から町まで動かしても、カクつきで操作を見失わない。
- 目的: 全国の形（約 1.7MB）と、県ごとの形、地理院タイルを重ねた地図が、実際のスマホで滑らかに動くかを見る。出典を地図の外（札の後、PC の幅では地図の右の欄）に全文で出していて、読めるかも見る。

## 準備

1. 開発機で LAN に公開して起動する（終わったら止める）。
   - `npm run dev -w web`（`vite --host 0.0.0.0`。既定のポートは 5173）
   - スマホで `http://<開発機の LAN アドレス>:5173/` を開く。同じ Wi-Fi につなぐ。
2. 事例の表示も見たいときは、過去のシーズン（昨季など）の棒を押す。今季の事例は、公開前の試験環境のデータがなければ 0 件になる。
3. 回線は Wi-Fi と、できれば携帯回線（4G または 5G）の両方で試す。携帯回線のときは、公開した環境（Hosting）で試す。

## 見ること

| 番号 | 操作 | 合格の見え方 |
|---|---|---|
| 1 | 開いて数秒待つ | 日本全体が見える。地図が真っ白のままにならない。読み込み中や失敗のとき、色がなくても「発生がない」と読める表示になっていない |
| 2 | ピンチで拡大・縮小（日本全体から町まで） | 指に遅れずについてくる。途中で止まって操作を見失わない |
| 3 | ドラッグで動かす | 同上 |
| 4 | 2 本指でひねる、2 本指で上下にずらす | 地図が回らず、傾かない |
| 5 | 全国の倍率で昨季を押す | 県ごとの件数のバッジが出る（1 件以上の県だけ）。バッジを押すとその県へ拡大する |
| 6 | 拡大して市町村の倍率（ズーム 6 以上）にする | 発生した市町村が塗られる。確定は単色、疑いは斜線 |
| 7 | 地図の外（札の後、PC の幅では地図の右の欄） | 出典（地理院タイル、Vector Map Level 0、国土数値情報）が全文で読める。出典は地図の外にあるので、地図の操作の邪魔にならない |
| 8 | 画面の下へスクロール | 棒、月別の表、リンク 8 つが順に出る。横にはみ出さない |

# 町の選び方の確認

設計書 §16「地図」の後半の条件を、60 代以上の人 1 人に確かめてもらう手順と記録。**まだ誰も確かめていない。** 結果の欄は空のままにしてあり、確かめた人が書く。数字や感想を推測で埋めない。

- 合格の条件（設計書 §16）: 60 代以上の 1 人が、説明なしで、迷わず自分の町を選んで 1 文まで着く。
- 氏名は書かない（「60 代の方」までにする）。詰まった場所と、そのとき言ったことだけを書く。

## 準備

1. 開発機で LAN に公開して起動する（終わったら止める）。`npm run dev -w web`
2. その人のスマホで `http://<開発機の LAN アドレス>:5173/` を開く。端末に前の記録（町や場所）が残っていないか確かめる（残っていたら、ブラウザの「サイトのデータ」を消す）。
3. 説明はしない。「自分の町が今どうなっているか、この画面で見てください」とだけ頼む。

## 見ること

| 番号 | 見ること | 合格の見え方 |
|---|---|---|
| 1 | 町を選ぶボタンを自分で見つけて押せる | 「自分の町」を押すか、地図の町をさわって選べる。探し回らない |
| 2 | 県 → 市町村の順に選べる | 選択欄の使い方で止まらない。「この町にする」を押せる |
| 3 | 画面の上に、自分の町の 1 文が出る | 1 文を読んで、何が起きているかを言える（「近くで出ています」「今のところ報告はないが油断できない」など） |
| 4 | 過去の 1 文（「昨季に隣町で発生しました（記録）」など）を、今の状況と取り違えない | 色のついた今の文と、色のない過去の文を区別できる |
| 5 | 「全国の動きをお知らせしています」を「何もない」「大丈夫」と読まない | 件数が少なくてもリスクがあることを言える（riskAnywhere の文を読んでいる） |
| 6 | 町を選び直せる | 「町を変える」で別の町にできる |
| 7 | （任意）くわしい場所を決める | 「地図で場所を合わせる」で、十字を合わせて「ここに決める」から「決める」まで着く。海の上や拡大不足のときの案内で止まらない |

## 不合格のときの直し方

1. 詰まった箇所の言葉を、その人の言葉に近づける（`web/src/pages/map/texts.ts`）。
2. ボタンの数と順を減らす（ふだん使わない「くわしい場所」は畳む）。
3. 直したら、もう一度、別の日に同じ手順で確かめる。結果は上の表に足す（前の記録を消さない）。
