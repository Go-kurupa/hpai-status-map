# 「くわしい場所を決める」の地図の直し

日付: 2026-11-06

## 症状（作者の報告）

PC 幅（64rem 以上）で「地図で場所を合わせる」を押すと、地図が描かれず真っ白になり、十字が左端に寄る。

## 原因（実測で確認。新しい E2E `web/e2e/spot-picker.spec.ts` で 1280x860 と 390x800、西粟倉村と真庭市）

- **A（PC）地図の箱が 2px に縮む。** 場所合わせ中は `map.css` の 64rem の media の中で `.map-page` を格子から縦並び（`display: flex`、`align-items: stretch`）に切り替える。同じ media の格子のための `.map-page > .map-box { align-self: start; }` が縦並びの中にも効き、地図の箱が中身の幅（枠線の 2px）まで縮む。直す前の試験: 地図の箱の幅 2（期待 1006 以上）で落ちた。
- **B（PC）十字が選んだ町の外に来る。** 場所合わせを始めると、地図の箱の幅が変わる（格子の左の列 → 全幅）のと同時に、選んだ町へ寄せる。寄せ先は地図がまだ古い幅のときに計算されるので、幅の差の半分だけ十字がずれる。A を直した後の試験: 十字の下の町が選んだ町ではなく隣の町で落ちた（アドバイザーの指摘で見つけた）。このまま「ここに決める」を押すと、隣の町で保存される。
- **C（大きな町）決められる拡大に届かない。** 寄せる広さは町の全体が入る広さ（`maxZoom: 11`）。真庭市のような大きな町では、決められる拡大（`SPOT_MIN_ZOOM = 10`）に届かず、そのまま「ここに決める」を押すと「もう少し地図を拡大して…」と出る。スマホでも起きる。

## 直し方

1. 先に落ちる試験を書く（済み）: `web/e2e/spot-picker.spec.ts`。押した後、地図の箱と地図の絵が親の幅いっぱいで、十字が地図の中央にあり、十字の下が選んだ町で、そのまま「ここに決める」を押すと「〇〇の上です」が出ること。
2. A: `map.css` の 64rem の media の中、場所合わせ中の `display: flex` の規則の直後に `.map-page:has(> .spot-picker[data-active="true"]) > .map-box { align-self: stretch; }` を足す。
3. B と C: `MapView` の `focus` に、場所合わせのときだけ `minZoom` を付ける。付いているときは、寄せる前に `map.resize()` で地図の大きさを測り直し、町の全体が入る寄せ先（`cameraForBounds`、`maxZoom: 11`）の拡大が `minZoom` 以上ならそこへ、届かなければ町の中心で `minZoom` まで寄せる。`MapPage` の場所合わせの開始（`aim`）だけが `SPOT_MIN_ZOOM` を渡す。ほかの寄せ方（全国、選択地域付近、町を選ぶ）は変えない。
4. 単体試験: 場所合わせを押すと `focus` に `minZoom = SPOT_MIN_ZOOM` が付き、「全国」に戻すと付かないこと（`MapPage.test.tsx`）。直しを外すと落ちることを確かめた。
5. 関係する試験（単体の地図と UI、E2E の map・shell・town・spot-picker）、型、build、公開前の検査を流す。

## 点検で見つかった直し（code-reviewer、中 1・低 4）

6. **中 1: 町の外枠の中心が町の外に出る町で、十字が隣の町に来る。** 町の外枠（四角）の中心で寄せていたため、形のいびつな町（全国 71 町。例 廿日市市 34213 は広島市、赤磐市 33213 は和気町の上）では、そのまま決めると隣の町で保存される。新しい `web/src/geo/interiorPoint.ts` で寄せる点を町の中に置く。偶奇則で外枠の中心が町の中かを判定し、外なら最大の面を高さの真ん中で横に切り、一番長い区間の真ん中を使う。`MapView` は描いた町の形を `shapesRef`（市町村コード → 形）に持つ。町の全体が入る広さで寄せるときも、外枠の中心が町の外なら同じ点で寄せる。緯度経度は保存も送信もしない（寄せる先の計算だけに使う）。試験: `interiorPoint.test.ts`（4 件）、E2E に廿日市市（1280）と赤磐市（390）の 2 件。`interiorPoint` を外すとこの 2 件が落ちることを確かめた。
7. **低 4: 町の形が届く前に押すと、場所合わせの寄せ先が消える。** 町の形が届いたときの「選択地域付近」への寄せ直し（`showNear`）が、先に始めた場所合わせの寄せを上書きしていた。`MapPage` に `aimingRef` を持ち、場所合わせの間は `showNear` を見送る。
- 寄せ方は、動きながら寄せる `fitBounds` から、一度に移す `jumpTo` に変えた。手順 3 の `map.resize()` を外しても E2E の 6 件は通ったので、B（十字のずれ）を実際に直しているのは `jumpTo` の方と推測する（点検役も同じ推測）。`resize()` は害がないので残すが、効いているとは確かめられていない。
- 点検の残り（低・好み）で手を付けなかったもの: 寄せる拡大を 10 ちょうどでなく 10.5 にする案、「やり直す」で合わせかけた位置が戻る件（直す前からの動き）。

## 確かめたこと（写し `fix/spot-picker`、基点 19746e0）

- 単体 4,349 件（skip 3）、型、build、権限 87 件、模擬環境 619 件、公開前の検査、E2E 165 件（spot-picker 6 件と explore を含む）がすべて通過（11/6 21:05）。
- 直しを外すと落ちる: CSS を外すと幅で 3 件、`interiorPoint` を外すと 2 件、`aim` の `minZoom` を外すと単体の 1 件。

## 作者の提案への答え

- 「市町村まで決めて、そこから自分で細かく選ぶ」: もともと押すと選んだ町へ寄る作りだった。A・B・C の直しで、PC でも大きな町でも、寄った先からそのまま十字で決められる。新しく外へ送るものはない。

## 範囲の外

- 番地の検索。番地を外の住所検索に送ることになり、設計書の決定「正確な地点は端末からも送らない」に反する。作らない。
- 現在地ボタン。PC から決めるときに使えないので作らない（作者の判断）。
- 地区名（大字・町丁目）で寄る機能。国土交通省の位置参照情報を使えば外へ送らずに作れる見込みだが、使用条件と大きさは未確認。この直しの後に、調べるかを作者と決める。
- 本番への反映。作者の「反映してよい」を取り、ほかのセッションと段取りを合わせてから行う。

## ほかのセッションとの関係

- 「データで探す機能」は、19746e0 で本番の反映を進めている。この直しはその反映に入れない。`MapView.tsx`・`MapPage.tsx` に触ることは事前に知らせた。commit はファイル名を指定して行う。
