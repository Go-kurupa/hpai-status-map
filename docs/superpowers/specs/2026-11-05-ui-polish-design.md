## 1. 目的と完了の条件

画面の点検で確かめた指摘を、締切までの 1 晩で直せる範囲に絞って直す。あわせて見た目を、平面で読みやすい方向へそろえる（4.6）。機能は足さない。

**完了の条件**

1. デモの順路（地図 → 再現 → 舞台裏 → 見本 → 鶏を飼っていない方へ → 試験の結果 → 全国の傾向）を、アドレスを打たずに画面のリンクだけで進める。
2. やることと記録のタブは見本の中にとどまる。ログインの画面へ飛ばない。
3. 幅 360px、高さ 740px で、次のものが最初の画面に入る。
   - `/`（町が未選択）: 町を選ぶボタンと地図、地図の直下の「色がない場所は…」の書き出し
   - `/sample/todo`: 再現の帯の見出し、題、時点、仮の地点。今の画面の帯（48px）は 6 章の例外。見本の「保存されない」の短い断り（入れた記録は保存されません）を再現の帯より前へ出す（全文は「くわしく」の中。作者の決定、8 章）
4. 再現で「次へ」を押すと、押したボタンの近くに今の出来事の 1 行と、メールの枠が出る。
5. 死亡数を保存すると、結果の枠まで画面が動く。鶏舎を切り替えても、前の鶏舎の数と除外の理由が残らない。
6. `/poster` は幅 360px で横にはみ出さず、印刷は今と同じ（A4 1 枚）。
7. `npm test` と `npm run typecheck` が通る。E2E は本体がまとめて回して通す（`live-smoke` を除く）。文の検査（`scripts/test/wording-sweep.test.ts`）も通る。
8. 新しく足した公開の文を、すべて 8 章に載せる（11/7 の共同経営者の確認に使う）。
9. 機械の検査が通る（CSS にグラデーション、影、ぼかしがない、角丸 4px 以下、絵文字なし、14px 以下の文字なし。既存の例外は 7 章。貼り紙の読み仮名は補助の文字として例外とし、画面では 8px を下限にする）。

## 2. 2 つの読者

| 読者 | 場面 | 困ること | この設計での扱い |
|---|---|---|---|
| 審査員 | デモの動画と、公開の画面を短時間で触る | 次に押す先が見えない。再現の結果が画面の外に出る。見本から本物の画面（ログイン）へ飛ぶ | 順路のリンク、今の画面の帯、再現の操作の並び替え |
| 高齢の現場の人 | シーズン中の朝にスマホで開く。デジタルに不慣れで、電波が弱い場所もある | どこを押すか迷う。押したあと何も起きないように見える。読めないのか、発生がないのか分からない | 動詞のあるボタン、押せない理由、押した結果へ画面を動かす、状態の見た目の統一 |

現場の原則は変えない。AI は下書きし人が確定する。入口は仕事の言葉にする。誇張しない。何もないことを安全と読ませない。

## 3. 今回の範囲の決まり【決定】

- 町の選択は押せない理由の表示だけ。現在地ボタンと郵便番号は足さない。
- ログイン画面（`pages/auth/LoginPage`）は変えない。
- `web/src/routes.tsx` は触らない。道筋の判定は `AppShell` の中で `useLocation` を使う。
- 公開の文面の意味を変えない。**新しい文は操作の案内だけにする。安全や状態に触れる文は足さない。** 既存の文の再利用はよい。
- 町を選んでいない最初の画面は地図を先にする。町を選ぶボタンは地図のすぐ上に置く。ボタンの名前を「町を選ぶ」に変えること、「農場の設定を開く」を足すこと、ボタンの移動はこの決定の範囲で、朝に報告する。
- `/public` と `/known` は目次を先頭に置き、本文は全部出す。畳まない。
- 自己点検は 4 択のままにし、押す部分を 48px にする。1 問ずつにしない。
- 地図が描けないことは利用者の環境の設定が原因の可能性が大きいので、WebGL の不具合を前提に直す項目を入れない。代わりの地図は消さない。
- 地図を入口にする決定と、親の「やらないこと」を破らない。外部データと新しい依存を足さない。Firestore の規則と関数は触らない。
- タブは 3 つのまま（親 15 章）。

## 4. 共通の部品の決定

### 4.1 押す大きさ

- ボタンとタブは今の 48px（`--tap`）のまま。
- 単独の行に置くリンクは `.tap-link` で高さ 48px にする。文の途中のリンクは行の高さのままにする（文面の流れを崩さない）。
- 題のリンク（`.app-title a`、今 24px）は 48px にする。出典のリンク（`.source-line a`、今 21px）は文の途中にあるので、`inline-flex` にせず `padding-block` で押す範囲を 44px 以上に広げる。
- 自己点検の 4 択のラジオは 48px にする（今 24px）。ラベル全体を押せる形は保つ。
- 県のバッジは 40px から 44px にする。48px は隣の県との重なりを実機で見ていないので今回は上げない【判断】。
- 下のタブの裏に要素が隠れないよう、`html` に `scroll-padding-bottom: 64px` を入れる。今の画面の帯（4.4）があるときは `scroll-padding-top: 56px` も入れ、画面を動かした先が帯の下に隠れないようにする。

### 4.2 状態の 3 種類の見た目

場所ごとに似た灰色の帯が並び、読めないのか、確認したのかが見分けられない。意味で 3 種類に固定する。色を増やさず、枠の線で分ける（段階の色と混ぜない）。**左の色帯は使わない。** 記号や文は足さない。

| クラス | 意味 | 見た目 | 使う場所 |
|---|---|---|---|
| `.state-ok` | 確認した | 1px の灰の実線の枠、地色なし | 見回りで全県を確認できたときの WatchLine |
| `.state-wait` | 読み込み中、確認中の発表がある | 2px の濃い灰の実線の枠、薄い灰の地 | 読み込み中の文、「確認中の発表がある県」 |
| `.state-unknown` | 確認できていない、読めていない | 2px の黒の破線の枠、薄い灰の地 | 未確認の県がある WatchLine、「今季の発生をまだ読めていません」、読めなかったときの文 |

`.state-ok` は緑や ✓ を使わない。安全と読ませないためである。点検の案にあった「だから安全とは言えません」の文は採らない（「安全」は書かない語）。

`.map-status` と `.town-now-wait` は残さず、この 3 種類に置き換える。`.class-if_in_zone` の左 10px は 3px の枠にする。「区域に入っていれば求められること」の見出しが同じ意味を文字で言っている。

左の帯で今回変えないもの: `.town-now`（段階の色）、`public.css:41`（公式の文の引用）、`explainer.css:29`（説明の引用）。どれも状態の 3 種類の外にある。

### 4.3 畳む部品

`details` 要素を `ui/Fold.tsx` と `.fold` で統一する。`summary` は高さ 48px で、開く内容を仕事の言葉で書く。**閉じていても本文は DOM に残す。** 畳むのは手順の説明と箇条書きだけ（6 章）。

使うのは `/replay` の日付の一覧の 1 か所だけにする。「前へ／次へ」と今の 1 行があれば通常は要らず、360px で約 700px を占める。

断りの箇条書きは畳まない。例外は再現と見本の説明で、作者の決定（2026-11-05）により、大事な 1〜2 行だけ出し、残りは「くわしく」で開く（理由: 警告文だけで地理的な把握ができないから）。

### 4.4 今の画面の帯

`AppShell` が `useLocation` で道筋を見て、ヘッダーの直下に 1 行出す。**再現と見本の中だけに出す。** 画面の上に固定し、下へ送っても今どこにいるか分かるようにする。印刷では隠す。

| 道筋 | 帯 | 押す先 |
|---|---|---|
| `/replay`、`/replay/…` | 去年の再現を見ています／再現を終わる | `/` |
| `/sample`、`/sample/…` | 見本の農場を見ています／見本を終わる | `/` |
| それ以外 | 出さない | |

- 「去年の再現です」の帯（親 17 章）は残す。今の画面の帯は、その帯の代わりではない。
- `/sample` の下では、やること → `/sample/todo`、記録 → `/sample/record/deaths` にする。地図は `/` のまま（見本の外へ出る。8 章）。帯のリンクは `.tap-link` にする。右上の「設定」は出さない（本物の設定へ飛ぶため）【判断、8 章で確認】。親 15 章の「設定は右上」は見本の外では変えない。
- 「記録」タブの行き先は `/record/deaths` にする（見本では上のとおり）。`/record` も `/record/deaths` も同じ `RequireMember` で包まれており、会員でない人に出るものは変わらない（`RecordPage.tsx`、`DeathsPage.tsx`）。「出力と削除」は記録の画面の小さいタブに残す。
- `NavLink` は `/record/deaths` を見るだけでは `/record/self-check` で光らないので、タブの選択中は `pathname` の前方一致で自分で判定する。

`/` 以外の一般の画面に「地図にもどる」を自動で出す案は採らない。`/known`、`/results`、`/area` は自前の戻るリンクを持ち、`/login` は変えない決まりで、`/poster` は印刷の高さの試験がある。戻るリンクのない `/privacy` と `/trends` にだけ、ページの中へ足す【判断】。

### 4.5 共通の文字と表

- `.as-of`、`.source-line`、`.tag` を 1rem にする。**14px 以下の文字を作らない。** 地図の出典、シーズンの棒の年の表記、比べの表も 1rem にする。
- 表は `.data-table` と `.table-scroll`（横に送る囲み）に統一する。太字の見出し行、見出しの下に 2px の黒の線、行の罫線は 1px。
- 数値のセルは `.num` にする。右寄せ、等幅の数字、折り返さない。文のセルと見出しは折り返す。`th[scope=row]` は最小 8em、`th[scope=col]` は最小 4em。
- `:root` に `color-scheme: light`。`.app-shell` の高さに `100dvh` を足す。

### 4.6 見た目の方向【決定】

東京都の対策サイト、デジタル庁のデザイン、Tableau のようなデータの見やすさを手本にする。AI っぽい見た目は避ける。今の `theme.css`（平面の単色、本文 18px、48px のボタン、行間 1.7）はすでにこの方向にあるので、ずれている所だけ直す。

| 採るもの | 値 |
|---|---|
| 灰を土台に、強調は既存の段階の色とアクセントだけ | 新しい色を足さない。緑を使わない |
| 字間と行間 | 本文の字間 .02em、行間 1.7。見出しの行間 1.5 |
| 見出し | h1 1.5rem、h2 1.25rem |
| 余白 | 8/16/24/48px の変数。同じ種類には同じ値 |
| 線 | `--line` を `#767676` に（区切りが見えるように） |
| 表 | 4.5 |
| 札 `.stat` | 2px の黒の枠、角丸 4px 以内、影なし。題 1rem → 値 1.5rem の太字 → 時点と出典。0 や少数も同じ大きさと中立の色 |
| 図 | 棒は 1 色で、数字を棒のそばに直接書く |

避けるもの: グラデーション、影、ぼかし、発光、角丸の大きいカードの羅列と入れ子、意味のない左の色帯、絵文字のアイコン、色の点だけの状態、緑の「問題なし」、大きな 0、中身のない見出し、意味のない動き、新しい依存。

デジタル庁の緑は「安全」の意味を持つので写さない。この作品は件数の少なさを安全と読ませない。

**公式に見せない。** デジタル庁のロゴ、国や都の紋章を使わない。素材の表に「デジタル庁デザインシステムの考え方を参考にした。デジタル庁が作成したものではない」と出典を書く（T13）。運営が民間であると画面で言う既存の文は見つかっていない。足さずに朝の質問にする。

**根拠と限界。** 2026-11-05 の調査で、次のページを読んだ。

- デジタル庁デザインシステム: https://design.digital.go.jp/dads/ と利用上の注意 https://design.digital.go.jp/introduction/notices/ 。色の値は未確認。
- 東京都の対策サイトのリポジトリ: https://github.com/tokyo-metropolitan-gov/covid19 。公開サイトはこの環境から開けず、実画面は見ていない。
- Datawrapper の色の記事: https://www.datawrapper.de/blog/colors/ 、FT の Visual Vocabulary: https://github.com/Financial-Times/chart-doctor/tree/main/visual-vocabulary 。
- Tableau の公式の本文は読めていない。「主要な数字を埋もれさせない」という一般の考え方だけを採る。大きな数字と小さなラベルの定型は避けるので、札の値は 1.5rem にとどめる。

## 5. 画面ごとの変更

### 5.1 地図 `/`

**並び（文面は変えない）**

今は 地図 → 地点の枠 → 凡例 → 断り の順で、任意の機能が断りより先に来る（`MapPage.tsx:147-188`）。

新しい並びは 地図 → 「色がない場所は…」 →（町を選んだ後だけ）町のボタンの行 → 凡例 → 読めていない文 → WatchLine → 確認中の県 → **札** → 出典 → 地点の枠 → 一覧 → シーズンの棒 →（以下は今のまま）。

- 十字合わせ中と、候補を確かめている間だけ、地点の枠を地図の直下に見せる。`SpotPicker` は内部に候補の状態を持つので場所を移すと状態が消える。DOM の位置は変えず、CSS の `order` と `:has()` で見た目だけ動かす。
- 「地図で場所を合わせる」を押したら、地図の枠の上端へ画面を動かす。十字と「ここに決める」が同時に見える。
- 地点の枠の「この端末の中に保存します。送信はしません」は保存と送信の断りなので畳まない。

**地図の高さと出典**

- 幅 40rem 以下だけ、地図の高さを `clamp(300px, 40vh, 480px)` にする。PC は変えない。十字は `--map-h` の半分で決まるのでずれない。
- 出典は全文のまま、地図の上から地図の外へ出す。360px で約 6 行になり、地図の下側を覆っているためである（`map.css:31-37`）。根拠: 地理院タイルの利用条件は「出典の明示」で、地図の上に置く決まりは `docs/data-sources.md` に記録がない。設定の地図（`MeshPicker.tsx:208`）と代わりの地図（`SvgMap.tsx:506`）は、すでに地図の外に同じ文を出している。文字は 1rem で、3 つの文を 1 行ずつ分ける。

**読みやすさ**

- 「色がない場所は…」は本文の大きさと本文の色にする。今は最も大事な文が最も弱い。
- 凡例を 1rem に上げる。シーズンの棒の年の表記を 1rem に上げる。比べの表も 1rem に上げ、`.data-table` と `.table-scroll` に入れて、狭い画面では表の中で横に送る（T12）。

**シーズンの棒**

- 左の欄に下限を持たせ、「確認できた範囲では 0 件（1 県は確認できていません）」のような長い文で見出しが 1 文字ずつ縦に潰れないようにする（`map.css:138-157`）。今季の行が崩れるので重要度が高い。
- 棒の枠を `--muted` にして押せるものに見せる。
- 棒を押したら地図の題へ画面を戻す。新しい文は足さない。町の 1 文を今季で計算する決まりは変えない（`MapPage.tsx:40`）。

**月ごとの表**

今季を見ているときに 47 県とも未確認なら、表の代わりに既存の「まだ確認できていません…」だけを出す。一部の県が未確認のときと過去のシーズンは今のまま（A1: 新しい状態の文を足さない。一部未確認の断りはすぐ上の WatchLine と棒が出している）。

**地図の部品の読み込み失敗**

地図の部品（別ファイル）を読めないと、今はページ全体が「表示中に問題が起きました」に替わり、町の 1 文と断りまで消える。地図の枠の中だけで受け止め（`routes.tsx` は触らない）、既存の「地図の形を読み込めませんでした…発生がないとは言えません」を出す。

**札**

今季を見ているとき（再現を除く）、確認中の県の直後に、平面の札を 2 枚出す。

| 札の題 | 値 | 文の出どころ |
|---|---|---|
| 発生した件数 | 今季の件数の文（`countText`） | `SeasonBar.tsx`。47 県とも未確認なら「まだ確認できていません」で、件数を見出しにしない（`MapPage.tsx:96-103`） |
| 時刻 | 最後に確かめた時刻（`WatchAsOf`） | `WatchLine.tsx`。確認できた県がないときは「最後に確認を試したのは…」。題を「時点」にしない（E2E が「時点」の語で時刻の表示を確かめており、題に入れると空振りする） |

新しい文はない。0 件も同じ大きさと色にする。

- 【判断】札は「地図の直下」ではなく、凡例と守る文の後に置く。地図のすぐ下に入れると、守る文（読めていない文、WatchLine、確認中の県）が札の分だけ下がるためである。朝に報告する。
- 【判断】4.6 の札は題 → 値 → 時点と出典の並びだが、ここでは時刻を 2 枚目の札にし、出典の行は足さない。今季の件数の出典を言う短い既存の文がなく、新しい文を足さないためである。朝に報告する。
- 【判断】「見回りの状況」の札は作らない。すぐ上の WatchLine が同じ文を枠付きで出している。札に繰り返すと、読み上げと試験の目印が二重になる。朝に報告する。

**地図の下のリンク**

順を現場に近い順にし、3 つ足す: 鶏を飼っていない方へ、分かっていること、全国の傾向、去年の再現、見本の農場、掲示用の貼り紙、試験の結果、プライバシー。`/trends` と `/poster` は入口がなかった。

**町の選択**

- 町が未選択のとき、地図より上にあるのは題、時点、町の短い行（「町を選んでください」）、ボタンだけにする。試験で確かめる。
- 町が未選択のときだけ、1 つ目のボタンを主ボタン「町を選ぶ」にする。「全国」は後ろの副ボタンにする。町を選んだ後は今のまま。今は「全国」「自分の町」が同じ重さで並び、定義済みの「町を選ぶ」が使われていない（`texts.ts:24`）。
- 「この町にする」が押せない間は、ボタンの下に本文の大きさで「県と市町村を選ぶと押せます」と出し、`aria-describedby` で結ぶ。`disabled` は残す。
- 農場の場所で見ているときは、理由の行を本文の大きさにし、「農場の設定を開く」を添える。再現の固定の場所は今の文のまま。
- 町を選んだ後は、ボタンの行（全国／自分の町／町を変える）を「色がない場所は…」の直後へ移す。断りは地図の直下に残す。地図を操作するボタンが地図に近づき、地図が上がる。開いた選択欄も地図の下になり、「地図の町をさわっても選べます」の案内が地図と同時に見えやすくなる。町が未選択のときは今の位置のまま（入口を最初の画面に置くため）。
- 「この町のくわしい状況」は `.tap-link` にする。

## 7. 試験の方針

- 変更と同じタスクで試験を直す。**確かめる内容を弱めない。** 文を探す試験は、文が同じなら残す。ボタンの名前が変わるときは新しい名前で同じことを確かめる。
- 新しい動きは先に試験を書く（TDD）。jsdom には `scrollIntoView` がないので、呼ぶ側は `el.scrollIntoView?.(…)` にし、試験は `Element.prototype.scrollIntoView` を差し替えて確かめる。
- `theme.css` に陰影とグラデーションを入れない（`ui.test.tsx`）。
- 機械の検査を `ui.test.tsx` に足す: `web/src` の CSS に `linear-gradient`、`radial-gradient`、`box-shadow`、`backdrop-filter`、`text-shadow` がない。`border-radius` は 4px 以下。画面の文字に絵文字がない（今の木で 0 件）。14px 以下の文字がない（T12 で足す。0.9rem の 14.4px は通る）。

- 新しい E2E は書かない。ボタンの名前や開く手順が変わって既存の E2E が動かなくなる箇所は、該当するタスクが押す手順だけを直す（確かめる内容は変えない）。E2E は本体がまとめて 1 本ずつ回す。`farm-profile` と `member-join` は各 spec の冒頭のコマンドで模擬環境を付けて回す。`live-smoke` は本番向けなので回さない。
