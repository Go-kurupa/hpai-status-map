# 画面の方向の設計

作者と見本（HTML）を見比べながら決めた。親の設計書は `2026-11-05-daily-overview-design.md`。件数を安全と読ませない決まり、断りの文、14px 未満にしない決まりは `2026-11-05-ui-polish-design.md` のまま。

## 1. 目的

同じ画面で、自分の近くを探すことと、全国を俯瞰することの両方を行う。スマホでは開いた瞬間に数字と地図の両方が目に入り、スクロールせずに判断できる。PC では並べて見比べられる。

## 2. 決まったこと

| 項目 | 決定 | 理由 |
|---|---|---|
| 組み方 | 幅で替える。スマホは罫線の組み方、PC は札の組み方 | 作者が見比べて、スマホは文書型、PC は札型が見やすいと判断した |
| スマホの参考 | NHK の感染者マップ。題 → 時点と大きな数字 → 切り替え → 地図 → 県別の棒 | 当時のサイトを開いて比べ、これが一番読みやすかった |
| 東京都の対策サイトから | PC の札ごとに時点と出典を添える。最終の時点を題のすぐ下に置く | いつの情報か確かめやすい |
| Tableau から | 週ごとの棒 | 波の形が一目で分かる |
| 色 | グラフ、タブ、ボタンは `#0017C1`（デジタル庁 blue-900）に白い文字。線と文字の灰色はデジタル庁の solid-gray（`#1A1A1A`、`#666666`、`#767676`、`#CCCCCC`、`#F2F2F2`）。発生は今の赤 `#B3261E` | 作者の好み。押す所もデータも同じ濃い青に決めた |
| 文字 | 本文 18px。スマホの札の題、断り、地図の説明は 14px まで下げてよい | 読みやすさを保ちつつ、最初の画面に地図を入れる |
| 札の順番 | 登録ありは「農場から約 60 km 以内」が先頭。登録なしはこの札を出さず「今季の全国」が先頭 | 毎朝まず近くを見る。審査員は全国から入る |
| 最初の地図 | 登録ありは自分の近く。登録なしは全国 | 地点がないと近くを描けない |
| 公的に見せない | 「民間の運営です。国や県の公式のサイトではありません。」を全画面に残す | デジタル庁の色を使うので、誤認を防ぐ |

## 2-2. 質感（ソフト）

作者が見本で「今の方向」と比べ、ソフトを選んだ。デジタル庁のデザインを土台に、shadcn/ui の Soft Minimal と Linear の情報階層を取り入れる。デザインシステムは置き換えない。

- **囲みを減らす。** カードは地図だけにする。札と断りは枠をなくし、余白と薄い線で分ける。黒い `2px` の枠の連続をなくす。
- **外周は 3:1 以上。** デジタル庁のカードの決まり（外周は必須で、影だけの境界は不可）に従う。地図のカードの枠は `#8C8C94`（背景 `#F8F8FB` に対して 3.15:1）。枠を一律に薄くしない。
- **装飾の区切りは低コントラストでよい。** `#E3E3E8`。押す部品と情報の境界は明確に保つ。
- **控えめな影と角丸。** 影は地図のカードとポップアップだけで、薄く 2 段。角丸はカード 12px、ボタンと切り替え 8px。派手なグラデーション、大きな角丸、過剰な動きは使わない。
- **紺が基調。** 題、見出し、数字は `#000060`（デジタル庁のダッシュボードの配色）。タブ、ボタン、今季の棒は `#0017C1` に白い文字。過去の棒は灰色 `#999999`。薄い文字は `#626264`、背景は `#F8F8FB`、切り替えの地は `#F1F1F4`。
- **題の帯は白に紺の文字。** 見本の既定のまま（作者の別の指示があれば替える）。
- **地図が主役。** PC は近くの地図を広く（3:2）。
- **変えないもの。** 感染情報の色分け、凡例、データの意味、機能、フォーカスの示し方。
- **AI っぽさを避ける。** 角丸のカードを並べない。カードは地図だけという決まりで保つ。

## 3. 画面

### スマホ（幅 40rem 以下）

上から順に並べる。見本の 360×740 で、地図は下のタブより上に全部入る。

1. 題の帯（作品名、設定）
2. `riskAnywhere`（14px、枠なし）
3. 「今季の発生（全国）」、時点と大きな数字、「直近 14 日 N 件」「農場から約 60 km N 件」の 1 行
4. 「自分の近く」「全国」の切り替え（登録なしは出さない）
5. 地図（横幅いっぱい）。輪の断りをすぐ下に 1 行
6. 近くの発生の表
7. 県ごとの今季の棒、週ごとの棒、同じ日までの件数の棒

未確認の県があるときの数字は `countText` の形にする。長くなるので、大きな数字にせず文の大きさにする。

### PC（幅 64rem 以上）

1. 題、時点
2. `riskAnywhere`
3. 札 4 枚（登録なしは 3 枚）。札ごとに時点か出典を添える（約 60 km の札は「距離は目安です」の断り）
4. 「自分の近く」と「全国」を横に並べる。登録なしは全国だけを広く出し、「町を選ぶ」を案内する
5. 県ごとの棒、週ごとの棒、同じ日までの棒

### 登録なしの案内

「町を選ぶと、近くの発生が見られます。」とボタン「町を選ぶ」を 1 行に並べる。

## 4. 地図の扱い

地図の操作は `private/requirements/map-ux-benchmark.md` を基準にする。ポップアップ、拡大の上限、シーズンの切り替えの位置は、作者と本物の画面を見ながら別に決める。今回の見た目の変更では動きを変えない。

PC で地図を 2 枚並べるので、MapLibre を 2 つ動かす。全国の地図は操作の負荷を確かめ、重ければ PC でも切り替えに戻す。

## 5. やらないこと

- 暗い表示。今のアプリは明るい表示だけなので、そのままにする。
- デジタル庁のパッケージを依存に足すこと。値だけを使う。
- 新しい機能（ポップアップ、全シーズンを重ねた地図など）。

## 6. 受け入れの場面

1. 360×740 で `/` を開くと、断り、数字、切り替え、地図が下のタブより上に入る（登録あり、なしの両方）。
2. 1280 幅で `/` を開くと、札が横に並び、地図が 2 枚並ぶ。
3. タブ、ボタン、棒が `#0017C1` で、タブの文字が白い。白に対する文字の濃さが足りている。
4. 全画面で 14px 未満の文字が増えず、横にはみ出さず、押す部分が 44px 以上のまま。
5. 未確認の県がある状態と 0 件の状態でも、数字が安全と読めない。
