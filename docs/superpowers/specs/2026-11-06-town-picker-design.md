# 自分の町の選び方と、町の欄の整理 設計書

- 日付: 2026-11-06
- 状態: 作者が了承（11/6。6 つの問いはすべておすすめの案）
- 元にした調べ: 本体の洗い出し 13 項目と、Fable のレビュー（コードで裏付け。画面は未撮影）
- 関係する設計書: `2026-11-06-ui-frame-design.md`（4.1 右の欄、4.2 自分の町の過去、決定 4・6）

## 1. 何が困っているか（作者の声）

1. 県と市町村をプルダウンでしか選べない。市町村の多い県では探すのが面倒。
2. 町を変えるボタンが自分の町の表示から離れていて、流れが分かりにくい。
3. 「自分の町の過去」の画面にある「この町のくわしい状況」を押しても、同じ内容に見える。

コードで確かめた原因:

- 町を選ぶ部品は県と市町村の select だけ（`TownPicker.tsx`）。決めるまで 4 回の操作。
- 「町を変える」は、町を選んだ後は地図や欄より後ろに単独で置かれる（`MapPage.tsx:684`）。`/town` には置かれない。
- スマホでは、選び直した後に地図が画面の外で動くので、変わったことが見えない。
- 選ぶ画面を開いている間は、地図を押すと「自分の町にする」になる。地図の近くにそれを示す印がない。
- 町を選び直すと鶏舎の場所（くわしい場所）が消えるが、知らせは消えた後にしか出ない。
- 最初の画面の自分の町の欄に「自分の町の過去を見る」と「この町のくわしい状況」の 2 つのリンクが並ぶ。
- 「選ぶ」が「自分の町を決める」と「地図で町を押して事例を見る」の 2 つの意味に使われている（「町を選ぶ」「選んだ町」）。

## 2. 決めたこと

| # | 決定 | 理由 |
|---|---|---|
| D1 | 「自分の町を変える」を、自分の町の欄の町の名前のすぐ横に置く。`/` と `/town` で同じ。地図の下の単独の置き場は無くす | 名前と変える口を近づける。`/town` で町を変えられない穴も同時に埋まる |
| D2 | 選ぶ画面の先頭に「町の名前を入力」の欄を足す。漢字の部分一致で、候補を「岡山県 西粟倉村」の形のボタンで並べる。**候補を押したらすぐ自分の町になる** | 速さを優先（作者の回答 1-A）。押し違えはもう一度選べば直る |
| D3 | 県と市町村の select は入力欄の下に残す | 文字を打つのが苦手な人のため |
| D4 | 読み仮名（ひらがな）での検索は入れない | スマホの入力は漢字に変換されるので、漢字の一致で足りる。外部データの照合と出所の確認が締切に合わない（回答 4-A） |
| D5 | スマホ（`useNarrow()` が true）では、町を決めたら画面を地図の上端まで戻す | 選び直した結果を見えるようにする |
| D6 | 選ぶ画面を開いている間（地図が描けるとき）は、地図のすぐ上に「自分の町を選んでいます。地図の町を押すと決まります」と［やめる］を出す | 地図を押したときの動きが変わることを、地図の近くで示す（回答 5-A） |
| D7 | 鶏舎の場所を決めている人には、選ぶ画面に「別の町にすると、くわしい場所は消えます（あとで決め直せます）」と前もって出す。消えた後の知らせも今のまま残す | 消えることを事前に分かるようにする |
| D8 | 最初の画面（`/`）の自分の町の欄からは「この町のくわしい状況」を外す。「自分の町の過去を見る」の 1 本にする。`/town` と押した町の欄には案内ページへのリンクを残す | 同じ行き先に見えるリンクを並べない（回答 2-A） |
| D9 | `/area/:muniCode` へのリンクの文を「この町の案内ページ（登録なしで開ける・共有用）」にする | `/area` は誰が開いても同じ、人に見せる用のページだと伝える。`/town` との統合はしない |
| D10 | 言葉を分ける。「自分の町」は自分の町を決めることだけ、「地図で押した町」は事例を見ることだけに使う（下の文言表） | 「選ぶ」の 2 つの意味をなくす（回答 3-A） |
| D11 | 地図で自分の町を押したときに自分の町の欄が隠れる作り（`map.css` の `:has`）は変えない。見出しの言い換え（D10）だけにする | 安全を優先（回答 6-A） |

## 3. 文言

| 場所 | 今 | 新しい文 |
|---|---|---|
| 町を選ぶ前のボタン（`TEXT.pickTown`） | 町を選ぶ | 自分の町を選ぶ |
| 町を選んだ後のボタン（`TEXT.changeTown`） | 町を変える | 自分の町を変える |
| select で決めるボタン（`TEXT.decideTown`） | この町にする | 自分の町にする |
| 地図で選べる案内（`TEXT.mapTapHint`） | 地図の町をさわっても選べます | 地図の町を押しても、自分の町にできます |
| 押した町の欄の見出しの札（`TEXT.panelLabel`） | 選んだ町 | 地図で押した町 |
| `/area` へのリンク（`TEXT.areaLink`） | この町のくわしい状況 | この町の案内ページ（登録なしで開ける・共有用） |
| 代わりの地図の読み上げ（`SvgMap.tsx:471`） | 。押すとこの町を選びます | 。押すとこの町を自分の町にします |
| 新: 入力欄の名前 | | 町の名前を入力 |
| 新: 入力欄の例 | | 例: 西粟倉 |
| 新: 候補がない | | 見つかりません。下の県と市町村からも選べます |
| 新: 候補が多い | | ほかに N 件あります。もう少しくわしく入力してください |
| 新: 選ぶ間の地図の上の文 | | 自分の町を選んでいます。地図の町を押すと決まります |
| 新: 選ぶのをやめるボタン | | やめる |
| 新: 鶏舎の場所が消える予告 | | 別の町にすると、くわしい場所は消えます（あとで決め直せます） |

町を選ぶ前の案内の文（「町を選ぶと、近くの発生が見られます。」）と、押した町の欄を閉じる「自分の町に戻る」は変えない。禁句（安全・安心・区域の外です）は使わない。

## 4. 入力で探す決まり

- 比べる前に、入力も町の名前も `normalizeForMatch`（`shared/src/text.ts`）で正規化する（全角と半角、空白、「ヶ」をそろえる）。
- 当てはまる町: 町の名前に入力を含む。または「県名＋町の名前」に入力を含む（「岡山西粟倉」のように続けて打つ人のため）。
- 並び: 名前が入力と同じ町、名前が入力で始まる町、それ以外の順。同じ順位の中は市町村コードの順。
- 出すのは 20 件まで。超えた分は数だけ伝える。
- 入力が空なら候補を出さない。1 文字から探す。
- かな漢字の変換の途中（composition の間）は「見つかりません」を出さない。
- 候補の文は「県名 町の名前」。同じ県に同じ名前の町がある（北海道の泊村）ときだけ、今の select と同じく末尾に（市町村コード）を付ける。

## 5. 今回はしないこと

- 読み仮名のデータの持ち込み（D4）。大会の後の候補: 総務省「都道府県コード及び市区町村コード」。カナの列の有無と利用の条件は未確認。
- `/town` と `/area` の統合。
- 「くわしい場所を決める」の部品の移動（PC の並びを崩しやすい）。
- 地図で自分の町を押したときに自分の町の欄を残す作り（D11）。
- 農場の設定画面（`/settings/farm`）の select。
- 地図の下の「自分の町の過去を見る」（`NextLinks`）は画面の行き先の一覧なので残す。
- メニューと画面の切り替えのタブ（`AppShell.tsx`、`SectionTabs.tsx`）。別のセッションの担当。
