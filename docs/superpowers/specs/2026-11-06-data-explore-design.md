## 1. 何が困っているか（作者の声）

1. 用途別（採卵と食肉）に、いつ、どれぐらい発生しているかを探したい。
2. 自分の羽数の規模と比べたい。少数飼育の人にも「少ないから発生しないわけではない」と伝えたい。
3. 東北、中国のような地方の単位で、過去の事例を見たい。
4. クリックで探せる、BI ツールのような性質がほしい。
5. 過去シーズンとの比べで、左右 2 枚の地図を見比べるのは手間。1 枚に重ねたい。余力があれば、3 つ以上も比べたい。

## 3. 決めたこと

| # | 決定 |
|---|---|
| E1 | 「過去の発生」の中に新しいタブ「条件で見る」（`/explore`）を足す。タブの並びは「全国とシーズン」「条件で見る」「選択地域のまわり」 |
| E2 | 条件は 3 段のボタンで選ぶ。文字を打たせない。**各段は複数選べる**（作者 11/6 夜。押すと入り、もう一度押すと外れる。「すべて」「全国」で選びを空に戻す。複数のときは、どれかに当てはまれば入る。「地図でこの地方を見る」は地方を 1 つだけ選んだときに出す）。<br>・用途: すべて／採卵鶏／肉用鶏／あひる／その他<br>・羽数: すべて／1,000 羽未満／1,000〜1 万／1 万〜10 万／10 万以上<br>・地方: 全国＋8 地方 |
| E3 | よく聞かれる問いのボタンを先頭に置く。押すと 3 段の条件がそのとおりに入る。<br>・採卵鶏ではいつ多い？<br>・肉用鶏ではいつ多い？<br>・1,000 羽未満でも発生はある？<br>・中国地方の過去は？ |
| E4 | 結果は 3 つを同時に変える。<br>・1 文: 「{条件} の過去 6 シーズンと今季: N 件」<br>・シーズンごとの件数の棒（過去 6＋今季）<br>・事例の一覧（日付、県と町、用途の元の表記、羽数、資料へのリンク）。新しい順 |
| E4b | （見本で確認中）月ごとの件数（今の「月ごとの件数と羽数」と同じく 10 月〜5 月を必ず出し、6〜9 月は事例があるときだけ。日付の記載がない事例は数を伝える）と、ボタンに件数を添える（その段以外の条件で絞った数。並べ替えない、割合を出さない）。助言役との相談で決めた案。作者の見え方の確認の後に作る |
| E5 | 用途のまとめ方: 元の表記に「採卵」を含めば採卵鶏、「肉用」を含めば肉用鶏、「あひる」を含めばあひる、それ以外はその他。記載なしは「記載なし」。一覧には元の表記をそのまま出す |
| E6 | 守ること。<br>・件数が 3 件以下のときは、守る文（FIXED_TEXT.riskAnywhere）を件数のすぐ下に出す。<br>・「件数は農場の数で割っていません。羽数帯や地方どうしの多い・少ないを表すものではありません。」を必ず出す。割合と順位は出さない。<br>・用途か羽数で絞ったとき、今季の事例でその項目が記載なしのものは数に入れず、「用途（羽数）の記載がない今季の事例 N 件は、この条件に入れていません」と出す。<br>・羽数は保存しない |
| E7 | 「地図でこの地方を見る」: 地方を選ぶと出す。押すと `/compare?region=<id>` を開き、その地方の広さに寄せる |
| E8 | 「過去シーズンとの比べ」（`/compare`）を、左右 2 枚から 1 枚の重ね合わせに替える。<br>・比べる 1 だけで発生した町: 「／」の斜線<br>・比べる 2 だけで発生した町: 「＼」の斜線<br>・両方で発生した町: 「×」の網目<br>・見せ方は「重ねる／1 だけ／2 だけ」<br>・地方のボタンで寄せる<br>・凡例に町の数<br>・町を押すと、2 つのシーズンの事例を 1 つの欄に上下に並べる（今の欄の中身を使う） |
| E9 | 重ね合わせの色は「橙と青緑」（比べる 1 #d97a00、比べる 2 #00857a、両方 #3b3b8f）。今季の確定に使う赤と取り違えないため。**作者の確認待ち。** |
| E10 | 今季を比べに選んだときは、疑いを含む今季の事例の町を「発生あり」とする。凡例に「今季は疑いを含みます」と添える |
| E11 | 地図が描けない端末（代わりの地図 SvgMap）でも、同じ 3 つの模様で重ねる |
| E13 | 重ね合わせの 3 つの層は、全国の広さから町を塗る（今の発生の層の minzoom を使わない）。見本と同じ見え方にするため。重ね合わせの間は、県ごとの件数の札（1 シーズン分の数）を出さない |
| E14 | 今季を比べに選んだときも、確認できていない県の印は消さない。ただし斜線「／」が比べる 1 の模様と同じ向きになるので、重ね合わせの間は灰色の薄い塗りに替える。凡例に「確認できていない県」を足す |
| E15 | `/compare` の広さのボタンは 1 段にまとめる。<br>・並び: ［選択地域付近］（地域を選んでいるとき）［全国］［北海道］…［九州・沖縄］<br>・押された印は、最後に押した 1 つだけ<br>・`?region=` で開いたときは、その地方に寄せ、選択地域付近へ寄せる最初の動きはしない |
| E16 | 「条件で見る」の今季の件数と棒は、確認できていない県があれば、今の画面と同じ断り（「確認できた範囲では N 件（M 県は確認できていません）」）にする。0 件を素の「0 件」と読ませない |
| E12 | 3 つ以上のシーズンの比べは余力。先に見本で見せ方を決める（斜線の向きは 2 つまでなので、「選んだシーズンのうち何シーズンで発生したか」を濃さで示す案） |
