## 2. 照合のやり方

- 取得は `politeFetch`（名乗りの User-Agent、robots.txt、同じホストへ 1.2 秒以上の間隔、再試行なし、TLS の設定は変えない）だけで行った。許可したホストは、農林水産省、厚生労働省、環境省、e-Gov、県のリンク先の確認だけ。
- 各文を、取得した本文（HTML は本文だけ、PDF は文字層、法令は e-Gov の法令 API v2 の本文）に対して、`normalizeForMatch`（NFKC、部首の表、空白の除去）を通して、**連続した文字列として含まれる**ことを機械で確かめた。34 文のうち 31 文は、そのまま一致した。
- PDF のページ番号が文の途中に混ざる 1 文（防疫指針の「公表する場合には…差し控える」）は、数字を除いて一致を確かめた。
- 環境省「死亡した野鳥を見つけたら」は画像の PDF で、文字層がない。**目で読んで**確かめた（2 文）。機械の照合はしていない。
- 法令は API v2 で取得した版（第 13 条の 2 は、レビュー 1 の後に 1 度取り直し、引用が一致することを確かめた。e-Gov の条へのアンカー `#Mp-At_13_2`、`#Mp-At_24` は画面の中の位置で、取得では確かめられない。ブラウザで開いて確かめる）で確かめた。家畜伝染病予防法は施行 2026-07-01 の版、同施行規則は施行 2026-10-01 の版（取得時に「現行」と返った版）。画面の出典の URL は、e-Gov の法令のページ。
- 同じ URL を 2 度取得したものがある（理由: 1 度目の結果を保存していなかった／本文が 8MiB を超え、取得の上限で中止された）。上限（`maxBytes`）を上げたのは、作業用の一時のスクリプトだけで、`politeFetch` 本体は変えていない（TLS の緩和ではない）。

## 4. 載せなかった文と理由

| 文、資料 | 理由 |
|---|---|
| 受診や相談の案内（農林水産省の「近くの保健所に相談し、…医師に連絡を入れてから診てもらいましょう」。厚生労働省の「医療機関を受診し」） | 設計書 §2「人の健康の質問に答えない。受診の助言をしない」。試験でも `/受診\|治療\|医師に\|病院へ\|保健所/` を禁じている |
| 受診の案内と取り違える禁止の表現 | 試験の禁止の表現は `(?<!獣)医師に`（レビュー 1 の裁定）。獣医師への届出を定める家畜伝染病予防法 第 13 条の 2 は、受診の案内ではないので、引用して載せた（出典と確認日つき）。「羽数の条件は書かれていません」は作品の文（`PAGE_NOTES`）で、上の条文の出典リンクを根拠として添える |
| 食品安全委員会の文書、厚生労働省 Q&A の「食品安全委員会も…『安全』とする見解」、県の資料の「安全」を含む表現 | 「安全」と書かない（§15）。題や文に「安全」を含む |
| 農林水産省の報道発表の「ヒトが…感染する可能性はないと考えております」 | 断定に近い。国の別の文（きわめて低いと考えられます）を使った |
| 「感染の心配はありません」「過度に心配する必要はありません」を含む文（農林水産省、環境省） | 安心させる言い方になる。同じ内容の別の文だけを使った |
| 環境省 野鳥の「日常生活において…手洗いとうがいをしていただければ、過度に心配する必要はありません」 | 同上 |
| 県の文だけが根拠の文（県の資料の「安全」を含む表現など） | 農場のある県のページは出典にしない（索引 Q14）。文が県の文だけのものは `PAGE_NOTES` かリンクに回すか、使わない |
| 「どの農場でも、許可なく入らない」「農場の場所を探さない」 | 県の文、または出典なしの作品の文。`PAGE_NOTES`（`approach`）に置いた |
| 特定症状の中身（告示） | 現行の告示を確かめるまで書かない（brief）。`PAGE_NOTES` は、施行規則の定義（法第 13 条の 2 第 1 項の症状）までにした |
| 防疫指針にある数の基準（「5 羽以上の家きんが、まとまって死亡している場合」など） | 県の対応や指導の中で使われる書き方で、飼い主の届け出や通報の義務の範囲とは別の文脈。混同を避けるため載せない |

## 7. 貼り紙

- 見出しは「防疫のため立入禁止」。難しい漢字に読みを付けた。連絡先は手書きの空欄。端に印刷日。QR は `${origin}/public`。
- 印刷する部分に、`/発生|鳥インフルエンザ|告|法律|罰則|安全|安心|心配/` の語がないことを単体の試験で確かめている。県や家保の看板に似せない（役所の書式、条文、罰則を入れない）。
- 文字の大きさは `poster.css` の変数（`--poster-h` 90pt、`--poster-sub` 40pt、`--poster-body` 24pt）。目安の 100pt、48pt、32pt では、読みの高さを含めると A4 1 枚に収まらない見積もりだったので、小さくした。**ブラウザでの測定は未**（`web/e2e/poster.spec.ts` を書いただけで、まだ回していない）。収まらないときは、まず `--poster-sub` を下げる。

4. 本番の URL の後に、A4 で印刷し、QR を読み取る。
