# Claude Code の使い方の記録

どの作業に、どのモデルを、なぜ使ったか。節目ごとに足す。実際に使ったものだけを書き、推測や後付けの理由は書かない。サブエージェントの役割は `.claude/agents/` にある（調査は `researcher`＝sonnet、レビューは `code-reviewer` と `security-reviewer`＝opus）。

公開前の検査の hook は、commit の前に stage の中身を調べる。`git add` と `git commit` は別のコマンドで行う（同じコマンドで続けると、add の中身を検査できない）。

| 日付 | 作業 | モデル | 理由 | 結果 |
|---|---|---|---|---|
| 2026-11-03 | 公開前の検査の hook と役割の分担、3 つの記録（X-03）の実装 | Sonnet 5.5（実装の部下） | 仕様と試験の中身が先に決まった実装で、判断が要る分岐は本体に戻す約束だったため。計画、検収、報告は本体が持つ | 試験を先に書いて落ちることを確かめてから hook を実装し、試験 64 件が通った。実際のリポジトリの全追跡ファイルの検査は、他の作業の試験用のメールアドレス（予約済みのドメイン）に一致して不合格になったため、除外を足すかを利用者の判断に回した |
