# Claude Code の使い方の記録

どの作業に、どのモデルを、なぜ使ったか。節目ごとに足す。実際に使ったものだけを書き、推測や後付けの理由は書かない。サブエージェントの役割は `.claude/agents/` にある（調査は `researcher`＝sonnet、レビューは `code-reviewer` と `security-reviewer`＝opus）。

公開前の検査の hook は、commit の前に stage の中身を調べる。同じコマンドで `git add <ファイル> && git commit` と続けても、add するファイルは一時の索引で stage を再現して調べる（リポジトリの索引は変えない）。中身が決まらない `git add -A`、`.`、`-u` と `git commit -a` は機械で止まる。
